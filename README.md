# Ruta del Agua

Frontend con React + Vite + TypeScript.

## Desarrollo

Requiere una versión de Node.js compatible con Vite (el proyecto se verificó con Node.js 20.20.2).

```powershell
cd D:\proyectos\ruta-del-agua
npm install
npm run dev
```

## Verificación

```powershell
npm run lint
npm run build
```

`npm run preview` sirve la compilación de producción localmente.

## Punto de partida

- `src/App.tsx`: pantalla inicial.
- `src/App.css`: estilos de la pantalla.
- `src/index.css`: estilos globales.
- `public/`: archivos estáticos.

Las vistas del cielo, agua, Luna, Marte y visibilidad local se implementarán a partir del diseño siguiente. Aladin Lite, Plotly y Leaflet se integrarán al desarrollar sus respectivas vistas.
